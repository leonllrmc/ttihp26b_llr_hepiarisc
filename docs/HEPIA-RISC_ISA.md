# HEPIA-RISC — Instruction Set Architecture (ISA) Reference

> Compiled from the *Laboratoire d'Architecture des Ordinateurs — Mini-projet : Processeur HEPIA-RISC* handout (hepia / HES‑SO, Prof. A. Upegui, PhD. L. Gantel).
> Modified by Léon Romanens

## 1. Architecture Summary

| Feature | Value |
|---|---|
| Instruction width | 16 bits, fixed length |
| Data width | 8 bits |
| General-purpose registers | 8 (`R0`–`R7`), 3-bit addressed |
| Register file ports | 2 read ports (A, B) + 1 write port (with write-enable), sync `reset`/`clk` |
| ALU | 8-bit, 3-bit opcode, flags `N Z C V` |
| Instruction memory | ROM, PC-addressed, 16-bit words |
| Data memory | RAM, 64 × 8-bit, addresses `0x00`–`0x3F` |
| Peripheral I/O | Memory-mapped, addresses `0x40`–`0xFF` |
| Addressing space (data+I/O) | 8 bits → 256 locations total |
| Special registers | `PC` (program counter), `Flags[3:0]`, `IRL` (interrupt link, not in register file) |

**Opcode design note:** the top bit of the 4‑bit opcode splits the instruction set in two:
- `0xxx` (opcodes `0000`–`0111`): **R‑type ALU instructions** — the low 3 bits of the opcode are fed *directly* into the ALU as its 3‑bit operation selector.
- `1xxx` (opcodes `1000`–`1111`): **extended instructions** — immediate load, branches, memory access, and function/interrupt control transfer.

## 2. Registers

### 2.1 General-purpose register bank

* 8 registers, `R0`…`R7`, each 8 bits wide.
* Ports:
  * Read port A: 3-bit address → 8-bit data out
  * Read port B: 3-bit address → 8-bit data out
  * Write port: 3-bit address + 8-bit data in + write-enable bit
  * `reset`, `clk` inputs

### 2.2 Special / implicit registers

| Register | Width | Description |
|---|---|---|
| `PC` | 8 bits | Points to the instruction to execute; incremented each cycle unless a branch/jump/interrupt overrides it. |
| `Flags` | 4 bits | Holds `N, Z, C, V` generated by the **last** instruction executed on the ALU. Bit order used for condition masking: **Z, N, C, V**. |
| `IRL` | 8 bits | *Interrupt Register Link* — internal CPU register (not part of the 8-register bank, not addressable by `RD`/`RS` fields). Holds the return address on interrupt to properly return to it with a BIR `RL`. |

### 2.3 Register usage conventions (software convention, not enforced by hardware)

| Register(s) | Convention |
|---|---|
| `R0`, `R1` | Function argument passing |
| `R0` | Function return value |
| `R2` | Scratch / temporary |
| `R7` | Commonly used as `RL` (link register) for `BL`/`BR` |
| `R0`–`R3`, `R7` | Usable freely by the main program (when interrupts are implemented) |
| `R4`, `R5` | Reserved for the interrupt-vector routine |
| `R6` | Reserved for the IRQ systick counter (if used) |

## 3. Memory Organization

### 3.1 Instruction memory (ROM)

* Read-only, holds the program; not modified during execution.
* Fetched from the SPI flash, with 2 contiguous bytes (16 bit in big endian)
* Addressed by `PC`; the `BL` immediate field is 8 bits wide, so the full design supports up to 256 addressable instruction words.
* Reserved locations when interrupts are implemented (see §9):

```
0x00        Reset vector   -> must contain: B 0x10  (unconditional jump to app start)
0x01–0x0F   Interrupt vector routine (15 words)
0x10 …      Application code (main)
```

### 3.2 Data memory (RAM)

* 64 × 8-bit, addresses `0x00`–`0x3F`.
* One write port, one read port (Using Yosys DFF RAM).
* Accessed only through `LD` / `ST` instructions, via a base register `RP` + immediate `offset`.

### 3.3 Memory-mapped peripherals (`0x40`–`0xFF`)

| Address range | Peripheral | Access |
|---|---|---|
| `0x00`–`0x7F` | RAM (128 registers) | LD / ST |

## 4. ALU

| Op (3b) | Mnemonic | Result |
|---|---|---|
| `000` | ADD | `A + B` |
| `001` | SUB | `A − B` |
| `010` | LSL | `A << 1` |
| `011` | LSR | `A >> 1` |
| `100` | ASR | `ASR(A)` (arithmetic shift right) |
| `101` | AND | `A and B` (bitwise) |
| `110` | OR  | `A or B` (bitwise) |
| `111` | NOT | `not A` |

Flags produced: `N` (negative), `Z` (zero), `C` (carry), `V` (overflow).

## 5. Instruction Formats

All instructions are 16 bits, `[15:12]` = opcode.

**R-type** (ALU, two operands) — opcodes `0000,0001,0101,0110`
```
[15:12] opcode   [11:9] RD   [8:6] RS0   [5:3] RS1   [2:0] reserved
```

**R1-type** (ALU, one operand) — opcodes `0010,0011,0100,0111`
```
[15:12] opcode   [11:9] RD   [8:6] RS0   [5:0] reserved
```

**I8-type** (load immediate) — opcode `1000`
```
[15:12] opcode   [11:9] RD   [8] reserved   [7:0] val (8-bit constant)
```

**Bcc-type** (conditional relative branch) — opcode `1010`
```
[15:12] opcode   [11:8] COND (4-bit)   [7:0] val (signed, relative)
```

**B-type** (unconditional relative branch) — opcode `1011`
```
[15:12] opcode   [11:8] reserved   [7:0] val (signed, relative)
```

**LD-type** — opcode `1100`
```
[15:12] opcode   [11:9] RD   [8:6] RP   [5:0] offset (unsigned, 0-63)
```

**ST-type** — opcode `1101`
```
[15:12] opcode   [11:9] RS   [8:6] RP   [5:0] offset (unsigned, 0-63)
```

**BL-type** (branch and link, absolute) — opcode `1110`
```
[15:12] opcode   [11:9] RegLink (RL)   [8] reserved   [7:0] val (absolute address)
```

**BR / BIR-type** — opcode `1111`
```
[15:12] opcode   [11:9] RegLink   [8:1] reserved   [0] Interrupt Flag
```
`Interrupt Flag = 0` → **BR**: `PC = [RegLink]` (register-indirect return).
`Interrupt Flag = 1` → **BIR**: `PC = [IRL]` (interrupt return; `RegLink`/reserved bits ignored).

| Opcode | Mnemonic | Format | Operation | Flags |
|---|---|---|---|---|
| `0000` | `ADD`  | R-type  | `RD = RS0 + RS1` | N Z C V |
| `0001` | `SUB`  | R-type  | `RD = RS0 − RS1` | N Z C V |
| `0010` | `LSL`  | R1-type | `RD = RS0 << 1` | N Z C V |
| `0011` | `LSR`  | R1-type | `RD = RS0 >> 1` | N Z C V |
| `0100` | `ASR`  | R1-type | `RD = ASR(RS0)` | N Z C V |
| `0101` | `AND`  | R-type  | `RD = RS0 AND RS1` | N Z C V |
| `0110` | `OR`   | R-type  | `RD = RS0 OR RS1` | N Z C V |
| `0111` | `NOT`  | R1-type | `RD = NOT(RS0)` | N Z C V |
| `1000` | `MOVI` (`RD = val`) | I8-type | `RD = val` | not specified in handout |
| `1010` | `Bcc`  | Bcc-type | `if (cond) PC = PC + val` | unaffected |
| `1011` | `B`    | B-type  | `PC = PC + val` | unaffected |
| `1100` | `LD`   | LD-type | `RD = Mem[RP + offset]` | unaffected |
| `1101` | `ST`   | ST-type | `Mem[RP + offset] = RS` | unaffected |
| `1110` | `BL`   | BL-type | `PC = val; RegLink = PC_old + 1` | unaffected |
| `1111` | `BR`   | BR-type (flag bit = 0) | `PC = [RegLink]` | unaffected |
| `1111` | `BIR`  | BR-type (flag bit = 1) | `PC = [IRL]` | unaffected |

## 7. Detailed Instruction Reference

### Arithmetic / logic (ALU) instructions
All of the form `RD = f(RS0 [, RS1])`; operands read from the register bank read ports, result written back to `RD` via the write port; ALU flags latched into `Flags`.

| Assembler | Encoding | Example |
|---|---|---|
| `RD = RS0 + RS1` | `0000 RD RS0 RS1 ---` | `0x0690` → `R3 = R2 + R2` |
| `RD = RS0 - RS1` | `0001 RD RS0 RS1 ---` | `0x1488` → `R2 = R2 - R1` |
| `RD = RS0 << 1` | `0010 RD RS0 --- ---` | `0x28C0` → `R4 = R3 << 1` |
| `RD = RS0 >> 1` | `0011 RD RS0 --- ---` | |
| `RD = ASR(RS0)` | `0100 RD RS0 --- ---` | |
| `RD = RS0 AND RS1` | `0101 RD RS0 RS1 ---` | `0x50D8` → `R0 = R3 AND R3` (used as `MOV R0, R3`) |
| `RD = RS0 OR RS1` | `0110 RD RS0 RS1 ---` | |
| `RD = NOT(RS0)` | `0111 RD RS0 --- ---` | `0x7240` → `R1 = not R1` |

> Trick: `AND` of a register with itself (e.g. `R0 = R3 AND R3`) is used as a pseudo `MOV`.

### `RD = val` — load constant
```
1000  RD  -  val[7:0]
```
Loads an 8-bit unsigned constant into `RD`. Example: `0x8242` → `R1 = 0x42`.

### `B val` — unconditional relative branch
```
1011  ----  val[7:0]
```
`PC = PC + val` (val is signed — two's complement, can jump forward or backward). Example: `0xBFFC` → `B -4`.

### `Bcc val` — conditional relative branch
```
1010  COND[3:0]  val[7:0]
```
`if (cond true) PC = PC + val`, else `PC = PC + 1`. `val` is signed. See §8 for the condition-code table. Example: `0xA4FB` → `BNS -5`.

### `LD RD, offset[RP]` — load from data memory
```
1100  RD  RP  offset[5:0]
```
`RD = Mem[RP + offset]`. `RP` supplies an 8-bit base address (register value), `offset` is a 6-bit unsigned displacement added to it. Example: `0xC685` → `LD R3, 5[R2]`.

### `ST RS, offset[RP]` — store to data memory
```
1101  RS  RP  offset[5:0]
```
`Mem[RP + offset] = RS`. Example: `0xD285` → `ST R1, 5[R2]` (writes `R1` to `Mem[R2 + 5]`).

### `BL [RegLink] addr` — branch and link (function call)
```
1110  RegLink  -  val[7:0]
```
Absolute jump: `PC = val`, and simultaneously `RegLink = PC_old + 1` (return address saved). Example: `0xEE0C` → `BL [R7] 12` (call function at address 12, save return address in `R7`).

### `BR [RegLink]` — branch register (function return)
```
1111  RegLink  --------  0
```
`PC = [RegLink]` — jumps to the address stored in `RegLink` (normally the register previously set by `BL`, e.g. `R7`). Example: `0xFE00` → `BR [R7]`.

### `BIR` — branch interrupt register (interrupt return)
```
1111  -----------  1
```
`PC = [IRL]` — returns from an interrupt service routine using the internal `IRL` register instead of a general-purpose register. Example: `0xF001` → `BIR`.

## 8. Condition Codes (for `Bcc`)

Flags are stored in the order **Z, N, C, V**. The 4-bit `COND` field selects one of the following conditions (the first four — `BZS`, `BNS`, `BCS`, `BVS` — are the minimal set introduced first; the full table is the final, complete set):

| Code | Mnemonic(s) | Condition | Meaning |
|---|---|---|---|
| `0000` | `BVC` | `V = 0` | Overflow clear |
| `0001` | `BVS` | `V = 1` | Overflow set |
| `0010` | `BCS` / `BGEU` | `C = 1` | Carry set / ≥ (unsigned) |
| `0011` | `BCC` / `BLTU` | `C = 0` | Carry clear / < (unsigned) |
| `0100` | `BNS` | `N = 1` | Negative set |
| `0101` | `BNC` | `N = 0` | Negative clear |
| `0110` | `BGT` | `Z = 0` AND `N = V` | > (signed) |
| `0111` | `BGE` | `N = V` | ≥ (signed) |
| `1000` | `BZS` / `BEQ` | `Z = 1` | Zero set / equal |
| `1001` | `BZC` / `BNE` | `Z = 0` | Zero clear / not equal |
| `1010` | `BLT` | `N ≠ V` | < (signed) |
| `1011` | `BLE` | `Z = 1` OR `N ≠ V` | ≤ (signed) |
| `1100` | `BGTU` | `C = 1` AND `Z = 0` | > (unsigned) |
| `1101` | `BLEU` | `C = 0` OR `Z = 1` | ≤ (unsigned) |
| `1110`, `1111` | — | — | unused / reserved |

Typical usage: subtract two operands (`SUB`) to set the flags, then follow with the appropriate `Bcc` (e.g. `SUB` then `BGT` to implement `if (a > b) ...`).

## 9. Interrupts (optional extension)

* On interrupt: `PC` jumps to the fixed **interrupt vector address `0x01`**.
* The return address is saved in **`IRL`** (not `RL`), so a function call/return (`BL`/`BR`) in progress isn't corrupted.
  * The return address is **not always `PC+1`** — if the interrupt occurs during a jump instruction, the return address is the *destination* of that jump.
* Address `0x00` (reset vector) must contain an unconditional branch to the real application start (convention used here: `B 0x10`), leaving addresses `0x01`–`0x0F` (15 words) for the interrupt routine.
* Context-saving convention to avoid saving the whole register bank:
  * `R0`–`R3`, `R7`: free for use by the main program.
  * `R4`, `R5`: reserved for the interrupt-vector routine's own use.
  * `R6`: reserved for the IRQ timer counter if used.
* Return from interrupt uses **`BIR`** (`PC = [IRL]`), distinct from the normal function-return `BR` (`PC = [RegLink]`) — both share opcode `1111`, disambiguated by bit `[0]` (the "Interrupt Flag").
* An interrupt is *not* itself an instruction (no explicit "call" instruction triggers it) — it behaves like an asynchronously-injected function call into the pipeline.

## 10. Assembler Syntax Cheat Sheet

```
RD = RS0 + RS1        ; ADD
RD = RS0 - RS1         ; SUB
RD = RS0 << 1           ; LSL
RD = RS0 >> 1           ; LSR
RD = ASR(RS0)            ; ASR
RD = RS0 AND RS1          ; AND
RD = RS0 OR RS1            ; OR
RD = NOT(RS0)                ; NOT
RD = val                       ; load 8-bit constant
B val                            ; unconditional relative branch
Bcc val   (e.g. BNS, BEQ, BGT…)   ; conditional relative branch
LD  RD, offset[RP]                 ; RD = Mem[RP+offset]
ST  RS, offset[RP]                  ; Mem[RP+offset] = RS
BL  [RegLink] addr                   ; call: RegLink = PC+1; PC = addr
BR  [RegLink]                         ; return: PC = [RegLink]
BIR                                    ; interrupt return: PC = [IRL]
```

## Appendix A — Example Programs (from the handout)

### A.1 Basic ALU test
```
0  0x7240  R1 = not R1        ; R1 = 0xFF
1  0x1488  R2 = R2 - R1       ; R2 = 1
2  0x0690  R3 = R2 + R2       ; R3 = 2
3  0x28C0  R4 = R3 << 1       ; R4 = 4
```

### A.2 Fibonacci (constants, loop, conditional branch)
```
0  0x8000  R0 = 0
1  0x8200  R1 = 0             ; init R1
2  0x8401  R2 = 1             ; init R2
3  0x0640  R3 = R1 + R0       ; temp = R1
4  0x0280  R1 = R2 + R0       ; R1 = R2
5  0x0498  R2 = R2 + R3       ; R2 = R2 + temp
6  0xA4FB  BNS -5             ; if N=1, restart at PC=1
7  0xBFFC  B -4               ; else loop back to PC=3
```

### A.3 Function call — `max(a,b)` called 3 times
```
; main
0  0x8602  R3 = 2
1  0x8803  R4 = 3
2  0x8A04  R5 = 4
3  0x8C01  R6 = 1
4  0x50D8  R0 = R3 AND R3     ; move R0 = R3 (arg)
5  0x5320  R1 = R4 AND R4     ; move R1 = R4 (arg)
6  0xEE0C  BL [R7] 12         ; call max
7  0x5368  R1 = R5 AND R5
8  0xEE0C  BL [R7] 12
9  0x53B0  R1 = R6 AND R6
10 0xEE0C  BL [R7] 12
; max: (addr 12)
12 0x1440  R2 = R1 - R0
13 0xA402  BNS 2              ; if R1<R0 (N=1), skip
14 0x5048  R0 = R1 AND R1     ; R0 = R1
15 0xFE00  BR [R7]
```

### A.4 RAM load/store
```
0  0x8242  R1 = 0x42          ; val
1  0x8420  R2 = 0x20          ; pointer
2  0xD285  ST R1, 5[R2]       ; Mem[0x25] = 0x42
3  0xC685  LD R3, 5[R2]       ; R3 = Mem[0x25]
```

### A.5 LED / Switch peripheral access
```
; write LEDs
0  0x8242  R1 = 0x42          ; Low LEDs = 0x42
1  0x84F1  R2 = 0xF1          ; High LEDs = 0xF1
2  0x8080  R0 = 0x80          ; pointer = 0x80
3  0xD200  ST R1, 0[R0]       ; Mem[0x80] = R1
4  0xD401  ST R2, 1[R0]       ; Mem[0x81] = R2

; echo switches to LEDs
0  0x8080  R0 = 0x80          ; LED pointer
1  0x8290  R1 = 0x90          ; Switch pointer
2  0xCA40  LD R5, 0[R1]       ; R5 = SW[7:0]
3  0xCC41  LD R6, 1[R1]       ; R6 = SW[15:8]
4  0xDA00  ST R5, 0[R0]       ; Low LEDs = R5
5  0xDC01  ST R6, 1[R0]       ; High LEDs = R6
6  0xB000  B 0                ; loop forever
```
